# University Learning Simulation

Проект моделирует учебный процесс в университете и анализирует результаты студентов.

## Что добавлено

- загрузка студентов из `data/students.csv`;
- запись среднего уровня знаний после каждой недели симуляции;
- график `results/knowledge_over_time.png` — средний уровень знаний по неделям;
- график `results/final_knowledge_by_student.png` — сравнение итоговых знаний студентов;
- исправлен импорт `Exam`: рабочая симуляция использует `src.univ.exam`, а не тестовый модуль.

## Запуск

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите симуляцию из корневой папки проекта:

```bash
python main.py
```

После завершения симуляции графики будут сохранены в папке `results/`.

## Тесты

```bash
python -m pytest -q
```

## Формат CSV

Файл `data/students.csv` должен содержать столбцы:

- `name` — имя студента;
- `motivation` — начальная мотивация;
- `energy` — начальная энергия;
- `knowledge` — начальный уровень знаний.
